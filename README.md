# 日払い 東京 LP v2

参考LPの構成に寄せて、TOPに実写写真を大きく使用したバージョンです。

## 公開方法
GitHubリポジトリ直下に以下をアップロードしてください。
- index.html
- style.css
- script.js
- privacy.html

## LINE URL
`https://lin.ee/XXXXXXXX` を実際のLINE公式アカウントURLへ全置換してください。

## 写真
TOP写真はUnsplashの外部画像URLを使用しています。
安定運用する場合は、公開前に画像を自前の素材へ差し替えることを推奨します。


## v3 update
